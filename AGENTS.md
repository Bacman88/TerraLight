# TerraLight — agent instructions

- At the start of every session, run `git pull --ff-only` before working on the project. If local changes or diverging history prevent the pull, preserve them and report the issue.
- At the end of completed work, run the relevant checks, commit the task changes, and push to the remote. Preserve unrelated local changes. If commit or push fails, report the issue.
- Communicate with the owner in Polish. Write code, code comments, and commit messages in English.
- Read `CLAUDE.md` for project context and firmware development rules.
